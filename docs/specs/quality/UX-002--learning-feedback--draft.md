# UX-002 · 학습·알림·다시 쓰기 화면 계약

구현 비종속. UX-001(비차단 이동·최소 질문·점진 공개·모션 품질)을 따른다.

| 계약 | 기준 |
| - | - |
| 학습 상태 보임 | 지시서마다 학습 상태(미분석·다시 분석·배운 것 n·새로 배운 것 없음, DATA-001)를 모양·글자로 표시하고, 미분석만 걸러 볼 수 있다. |
| 지시서 서랍 | 어느 화면에서든 열고 닫는 목록. 화면을 막지 않고(포커스 가둠·배경 잠금 없음), Esc·바깥 버튼으로 닫는다. 행: 제목·전달 가능 여부·학습 상태·원본. 행에서 열기·복제(FLOW-002). |
| 위에서 아래로 | 취향 노트는 묶음 → 원칙 → 기준 순으로 보인다. 원칙은 접힌 상태에서도 문장·하위 개수·근거 강도·확인할 개수를 보인다. 확인할 기준이 있는 원칙만 처음에 펼친다. |
| 펼치기 | 클릭·키보드·터치로 동작하는 펼치기를 쓴다. 호버는 미리보기 보조로만 쓰며 정보의 유일한 길이 되지 않는다. |
| 알림 3단계 | ① 제자리: 행동한 곳에 잠깐(되돌리기 포함), ② 배지: 쌓인 할 일 개수(확인할 취향·미분석 지시서), ③ 배너: 작업을 방해하는 문제(연결 끊김·저장 실패)만. 팝업·모달은 쓰지 않는다. 같은 알림은 반복하지 않는다. |
| 출처 추적 | 기준의 출처 지시서로, 지시서에서 그 지시서가 낳은 기준으로 이동할 수 있다. |
| 모션 | 펼치기·서랍은 transform·opacity로만 움직이고, 높이는 애니메이션하지 않는다. 하위 항목은 짧게 차례로 나타난다. 동작 줄이기 설정이면 즉시 나타난다. |

- 측정: UX-001 모션 기준(프레임 p95 16.7ms)을 서랍 열기·원칙 펼치기에도 적용한다. 서랍과 펼치기는 키보드만으로 열고 닫을 수 있다.
