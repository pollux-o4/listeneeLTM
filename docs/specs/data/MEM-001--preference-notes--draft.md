# MEM-001 · 취향 노트

사용자의 질의·요구 패턴에서 드러난 판단 기준을 프로젝트에 쌓아, 다음 작업자(AI·사람)가 같은 설명을 다시 듣지 않게 한다. 결정: ADR-0006.

- 저장: `.ltm/preferences.json`(커밋 대상). 항목은 묶음(자유 문자열), 기준 한 문장, 근거(최근 8개), 작성자, 확인 여부, 내려놓음 여부로 이뤄진다.
- 쌓기: AI가 관찰해 `note`로 기록한다. 묶음과 기준 문장이 같으면 새 항목 대신 근거를 더한다(반복 관찰 = 강화). 사용자에게 채우라고 요구하지 않는다.
- 사람의 역할: 확인, 고치기, 내려놓기, 다시 적용. 내려놓은 항목은 지우지 않고 보존한다. AI가 같은 기준을 다시 관찰하면 근거만 쌓이고, 다시 적용은 사람만 한다.
- 읽기(맥락 절제): `ltm pref show`는 활성 항목만 묶음별로 출력하고 근거는 개수만 보여준다. 확인 전 항목에는 "(확인 전)"을 붙인다.
- 금지: 원문 인용, 개인정보, 일회성 지시.
- 실패: 빈 문장과 없는 id는 거부하고, 아무것도 바뀌지 않는다.

검증: `crates/ltm-core/tests/mem_001.rs`, `crates/ltm-server/tests/flow_001.rs`
