# ADR-0008 · 취향 노트는 원칙-기준 2단, 학습 상태는 지시서에

- 맥락
  - 취향 노트(ADR-0006)는 쓸수록 비슷한 기준이 쌓여 훑어보기 어렵고, AI가 읽는 맥락도 커진다.
  - 어떤 지시서에서 무엇을 배웠는지, 아직 분석하지 않은 지시서가 무엇인지 알 수 없어 관리가 어렵다.
- 대안
  - 평면 목록 유지 + 개수 상한만 둔다.
  - 임의 깊이 트리.
  - 원칙(상위) 아래 기준(하위) 2단. 근거에 출처 지시서를 남기고, 지시서에 분석한 버전을 남긴다.
- 선택: 2단 구조와 출처·분석 버전 기록(MEM-001, DATA-001).
  - 원칙은 비슷한 기준 여럿을 아우르는 한 문장이다. 하위 기준은 지우지 않고 구체 예로 남는다.
  - 깊이는 2단으로 고정한다. 더 깊으면 탐색 비용이 이득보다 크다(묶음 3~5 · 원칙 5 상한으로 충분).
  - 학습 상태는 저장하지 않고 계산한다: 지시서의 `analyzedRevision` + 노트 근거의 출처 지시서. 단, "분석했지만 배운 것 없음"은 계산할 수 없어 분석 버전만 저장한다.
- 이유
  - 사람은 원칙만 훑고 필요할 때 펼친다(점진 공개). AI는 원칙과 확인된 기준만 읽어 맥락이 작다.
  - 출처가 있으면 노트 ↔ 지시서를 오가며 근거를 검토할 수 있다.
- 결과
  - 묶기·풀기는 연산(`group`·`ungroup`)이다. AI가 제안하면 확인 전이고 사람이 확인한다.
  - 학습은 모델 학습이 아니라 사람 피드백으로 노트를 다듬는 것이다. 문서에서 "강화학습"이라 부르지 않는다.
