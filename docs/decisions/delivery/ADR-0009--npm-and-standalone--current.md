# ADR-0009 · npm·단독 실행 파일 배포

- 맥락: 한 줄 설치 뒤 AI와 GUI가 같은 프로젝트를 사용해야 하며, 개발 도구가 없는 PC도 지원한다. 사용자 요청으로 설치·배포 방식을 확정한다.
- 선택: `pnpm add -D listenee-ltm`으로 플랫폼별 선택 의존성을 설치한다. `ltm init`은 `.ltm/AGENTS.md`와 프로젝트 안내 포인터를 등록한다. `ltm ui`는 브라우저를 연다.
- 대안: 소스 빌드는 사용자에게 개발 도구를 요구한다. npm만 제공하면 Node 없는 PC를 지원하지 못한다.
- 이유: Rust 단일 바이너리·UI 내장(ADR-0003)을 유지하면서 기존 패키지 관리와 단독 다운로드를 함께 지원한다.
- 결과: Linux x64(musl), macOS arm64, Windows x64 실행 파일과 체크섬을 같은 버전으로 배포한다. npm 런처만 Node를 사용하며 단독 파일은 Node·Rust가 필요 없다. 설치 스크립트는 버전을 고정하고 자동 업데이트하지 않는다.
- 범위 밖: MCP 등록·수익화·자동 업데이트. GitHub Release와 npm 최초 공개·인증 설정은 릴리스 운영에서 수행한다.

계약: INSTALL-001.
