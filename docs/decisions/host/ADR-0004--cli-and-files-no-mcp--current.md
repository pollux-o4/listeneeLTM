# ADR-0004 · AI 연결은 CLI·파일·안내 문서로 (MCP 없음)

대체: ADR-0003의 MCP 연결 부분

- 맥락: AI가 별도 학습 없이 LTM을 발견·호출해야 한다(FLOW-001, UX-001 무학습 사용). Storybook·Vite 같은 AI 친화 라이브러리는 MCP 없이 파일·CLI·문서로 쓰인다.
- 대안: MCP 서버 / CLI + 파일 + 안내 문서.
- 선택
  - `ltm init`이 `.ltm/AGENTS.md`(AI용 사용 안내)를 쓰고, 프로젝트 AGENTS.md(있으면 CLAUDE.md도)에 안내 문서를 가리키는 한 줄을 추가한다.
  - AI는 `ltm new·list·check·set`(JSON 출력)을 실행하거나 `.ltm/briefs/*.json`을 직접 편집한다.
- 이유
  - 호스트별 등록이 필요 없고, 셸과 파일을 다루는 모든 AI 호스트에서 동작한다.
  - 지시서가 평범한 파일이라 Git으로 이력을 남기고 비교할 수 있다.
  - 의존성과 코드가 줄었다. release 바이너리가 3.2 MB에서 1.9 MB가 됐다.
- 결과: 셸이나 파일에 접근하지 못하는 데스크톱 채팅 호스트는 지원하지 않는다. 필요해지면 같은 저장소 위에 얇은 어댑터를 추가하는 것을 검토한다.
