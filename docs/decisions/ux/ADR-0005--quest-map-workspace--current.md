# ADR-0005 · 작업 화면은 여정 지도 구조

- 맥락: 사람이 AI가 채운 것, 내가 정할 것, 바뀐 것, 최종 결과를 한눈에 구분하고 조작해야 한다(UX-001 한눈에 파악·최소 질문·공동 편집). 도트 아트에 부드러운 모션을 더한 시각 방향을 전제로 한다.
- 대안: `ui/prototype/pixel-ui`의 A 작업대(3열 문서), B 여정 지도(단계 길과 갈림길), C 한 가지씩(판단 카드와 미리보기).
- 선택: B 여정 지도를 뼈대로 A·C의 장점을 합친 정본. 제품 구현은 `ui/src/features/brief`.
  - 섹션은 길 위의 단계로 보여주고, 한 번에 한 단계만 펼친다.
  - 결정이 필요한 곳은 갈림길로 표시하고, 추천 선택지와 이유를 함께 보여준다.
  - 마스코트가 현재 단계에 서서 그 자리에서 말하고(말풍선), 모두 완료하면 전달 상자가 열려 완성된 지시서를 보여준다.
  - A에서 가져온 것: 작성자 표시(AI·나), 항목 직접 추가·삭제, 변경 기록, 되돌리기, 단계 타일의 "확인 전" 개수.
  - C에서 가져온 것: 조립 중인 지시서 미리보기(새 줄 강조), 남은 갈림길을 추천대로 한 번에 처리.
  - 미리보기가 A의 전체 훑어보기를 대신한다. 미리보기의 제목을 누르면 해당 단계로 이동한다.
- 이유: 사용자가 시안 3종을 비교해 선택했다(2026-11-11). 초보 사용자의 "지금 어디, 다음 뭐"에 가장 직접 답한다는 가설과도 맞는다. 사용자 테스트는 아직 하지 않았다.
- 결과
  - 도메인 모델(DATA-001)에 갈림길, 작성자, 확인 여부, 변경 기록, 판정(`BriefView`)을 추가했다. UI는 판정을 다시 계산하지 않는다.
  - 대비 기준: 본문·보조 텍스트는 두 테마 모두 4.5:1 이상으로 맞췄다(토큰 `--c-muted`, `--c-accent`).
