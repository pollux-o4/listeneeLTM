# ADR-0001 · 소비자 이상향 역설계, AI가 기본 조작자

- 맥락: 사용자 역량과 무관하게 지시서 품질 하한선을 높여야 한다(VISION-001).
- 대안: 전용 챗봇 서비스 / 중앙 프로젝트 관리 화면 / 설치형 라이브러리 + 기존 AI 호스트 연동.
- 선택: 프로젝트별 설치형 라이브러리. 설치 대상 분야를 사전에 알지 않는다. AI가 기본 사용자·조작자이고, 사람은 자연어로 AI에게 요청하거나 같은 GUI·데이터를 직접 편집한다.
- 이유: 사용자가 새 도구 사용법을 배우지 않고(UX-001 무학습 사용) 이미 쓰는 AI를 유지한다. 프로젝트 맥락을 로컬에서 격리해 읽을 수 있다.
- 결과: 전문 지식 검색·검증·변경 관리는 품질 하한선을 위한 수단으로 우선순위를 정한다. 호스트별 연결 방식 차이를 감수해야 한다(`host/` 미결).
