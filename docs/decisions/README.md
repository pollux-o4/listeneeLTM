# 결정 기록

규칙: RULE-ADR. 현재 결정: `rg --files docs/decisions | rg -- '--current\.md$'`.

## 관심사 (폴더 = 관심사, 미결은 결정 시 폴더 생성)

| 관심사                                                | 상태                            |
| ----------------------------------------------------- | ------------------------------- |
| `product/` 방향·첫 사용자군·우선 도메인               | 방향 확정, 사용자군·도메인 미결 |
| `host/` 지원 AI 호스트·발견·호출·권한 연결 | CLI·파일 방식 확정(ADR-0004), 첫 검증 호스트 미결 |
| `editing/` 공동 편집 정보 구조·충돌·되돌리기 | 작성자·확인·되돌리기·쓰기 잠금 구현(DATA-001), 같은 항목 충돌 알림 미결 |
| `knowledge/` 분야 지식 수집·검증·갱신                 | 미결                            |
| `memory/` 프로젝트 기억·버전 관리 범위 | 취향 노트(ADR-0006), 원칙-기준 2단·학습 상태(ADR-0008), 지시서 되돌리기 스냅샷(DATA-001) |
| `delivery/` 패키징·설치·연결 자동화·로컬 UI·배포·수익 | Rust 단일 바이너리·UI 내장(ADR-0003), npm·단독 파일 배포(ADR-0009), 수익 미결 |
| `ux/` 작업 화면 구조·시각 방향 | 여정 지도 정본 제품 반영(ADR-0005), 다국어는 끝단에서(ADR-0007) |
