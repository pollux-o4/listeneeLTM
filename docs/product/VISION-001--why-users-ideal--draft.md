# VISION-001 · 존재 이유·사용자·이상향

## 핵심 가치

결과물(과업지시서)의 **품질 하한선을 높인다.** 전문 지식 탐색·질문·검수·변경 관리는 수단이다.

## 해결할 문제

지식·경험·표현력·투입 시간에 따라 지시서 완성도가 크게 갈리고, 모호하거나 빠진 요구가 시행착오·재작업·분쟁으로 이어진다. 숙련자도 같은 원칙을 반복 설명한다.

## 만들고 싶은 변화

생각의 완성도와 관계없이 프로젝트 안에서 시작하면, 도구가 맥락을 읽고 부족한 부분을 보완하며 중요한 결정을 도와 실행 가능한 지시서까지 이끈다.

## 목표 사용자

- 초보자: 무엇을 요구할지 모름 → 생각 구조화.
- 일반: 목표는 있으나 세부 조건·검수가 흐릿함 → 누락 보완.
- 숙련: 자기 원칙 보유 → 반복 지시 감소.
- 진행 중 프로젝트: 변경·유지보수·마감 통제 → 이전 결정 재사용.

## 이상향 장면

1. 모르는 사용자: "뭘 해야 할지 모르겠어" → AI가 LTM으로 목적·현 상태·빠진 요구를 GUI에 정리, 사용자는 맡기거나 직접 수정.
2. 아는 사용자: "전에 정한 기준 지키면서 이 기능만" → 기록된 제약·품질 기준을 이어받아 변경 범위 정리.
3. 마감 전: "내일 끝내야 해" → 목표·결정 기준으로 남은 위험·미충족 조건 정리.

궁극 반응: "설명을 잘 못해도 의도를 발전시켜 줬고, 한 번 결정한 건 기억해 줬다."
