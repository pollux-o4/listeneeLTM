# VISION-003 · 초기 검증 방향

## 먼저 검증할 경험

연결된 프로젝트에서 사용자가 AI에게 한 문장만 말하면 AI가 LTM을 자동 호출해 GUI에 실행·검수 가능한 지시서를 채우고, GUI와 AI 양쪽에서 수정할 수 있는가. 계약: `FLOW-001`.

- 범위: 지원 AI 호스트 1개 × 프로젝트 1개를 끝까지 연결. 다른 호스트·분야 확장은 이후.
- 제외: 자체 대화 모델, 중앙 대시보드.

## 성공 판단 질문

- 적게 생각한 사용자도 일정 수준 이상 구조화된 결과를 받는가?
- 입력량·전문 지식 차이가 품질에 주는 영향이 줄어드는가?
- 질문이 정말 필요한 결정에 집중되는가?
- 빠진 요구·모순의 뒤늦은 발견이 줄어드는가?
- 반복 설명·재작성 수고가 줄어드는가?
- 전문성 보완이 불필요한 복잡도 없이 품질을 높이는가?

기준·목표 수치는 평가 설계·사용자 테스트로 정한다.
