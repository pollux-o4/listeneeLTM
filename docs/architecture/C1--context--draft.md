# C1 · 시스템 맥락 (초안)

```
사용자 ──자연어──▶ AI 에이전트(셸·파일 접근) ──ltm CLI·파일 편집──┐
  │                       └─ 읽기: .ltm/AGENTS.md 안내          ▼
  └──클릭·입력──▶ LTM GUI(ltm ui, 127.0.0.1) ──HTTP──▶ ltm ──▶ .ltm/ (프로젝트 안)
                                                                ├─ briefs/*.json   지시서(커밋)
                                                                ├─ preferences.json 취향 노트(커밋)
                                                                └─ history/        되돌리기(커밋 제외)
```

- 경계: 프로젝트 하나 = 맥락 하나. 다른 프로젝트 정보는 들어오지 않는다. 네트워크는 루프백만 쓴다.
- 연결: AI와 사람은 같은 `.ltm/` 파일을 고치고, 쓰기 경로(CLI = AI, HTTP = 사람)로 작성자를 구분한다(ADR-0004, DATA-001).
- 범위 밖: 셸·파일에 접근하지 못하는 채팅 호스트(ADR-0004).
- 미결: 첫 검증 호스트 → `decisions/README.md`. 설치·배포: ADR-0009. C2(실행 단위)는 `tech-spec.md` 구조 참조.
