# Prototype · Pixel UI (보관)

질문: 사람이 "AI가 채운 것 / 내가 정할 것 / 바뀐 것 / 최종 결과"를 어느 구조에서 가장 쉽게 파악하고 조작하는가.

판정: B 여정 지도를 뼈대로 A(작성자 표시·직접 편집·기록·되돌리기)와 C(실시간 미리보기·추천 일괄 처리)를 합친 정본을 채택했다(ADR-0005). 제품 구현은 `ui/src/features/brief`에 있다.

이 폴더는 비교 근거로만 남긴다. 빌드·타입 검사·Storybook에서 제외되며 더 다듬지 않는다. 실행하려면 `pnpm prototype`을 쓴다.
