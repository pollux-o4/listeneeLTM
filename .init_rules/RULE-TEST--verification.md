# RULE-TEST · 계약 ID와 검증 증거

- 명세 ID 대응
  - SAVE-001 → `save_001.rs` 또는 기존 테스트의 `save_001` 모듈·함수 접두어.
  - 정규화는 프로젝트별로 통일하고 테스트 발견 여부를 확인한다.
- 배치
  - 기존 테스트를 재사용하고 계약별 사례를 묶는다.
  - 복수 계약의 통합 테스트: 대표 관심사 경로와 `검증: ID 목록`.
- 명세 변경 시 대응 ID의 테스트·미검증 부분을 확인한다.
- 검증 기록
  - 이후 판단에 재사용할 기준 측정값·재현 근거만 보존한다. 작업 완료 보고·일회성 검증 결과는 별도 문서로 만들지 않는다.
  - 보존할 때는 명령·환경·결과·미검증 범위를 적고, 합성 probe와 실제 앱 측정을 구분한다.
