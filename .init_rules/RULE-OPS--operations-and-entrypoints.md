# RULE-OPS · 운영 안내와 구조 지도

- 진입점
  - AGENTS.md: 안정적인 작업 원칙·관심사별 탐색 키.
  - README: 사람용 목적·빠른 시작·짧은 운영 절차.
  - 진입 안내는 관심사·탐색 방법으로 고정하고, 현재 파일·ID·심볼 목록은 검색으로 찾는다.
- 운영
  - 절차가 커지면 `operations/recovery/OPS-001--restore-data.md`처럼 작업별로 분리한다.
  - 작업별 선행 조건·실행 절차·성공 확인·실패 대응을 기록한다.
  - 현재 내용으로 갱신하고 과거 버전은 Git으로 보존한다.
- 로그·출력
  - 기록·조회는 필요한 범위·양·기간으로 제한한다.
  - 원인 불명확 시 확장하고 진단 후 기본 수준으로 되돌린다.
  - 일회성·누적 로그·도구 출력·시험 결과·보고서는 근거 확인 후 정리한다. 감사·보안·복구·재현 기록은 보존 기준을 적용한다.
- C4: `architecture/`
  - C1: 맥락. C2: 실행·저장 단위.
  - C3: 관심사별 컴포넌트. 예: `03-persistence-components.md`.
  - C4 Code: 컴포넌트 키워드·대표 심볼로 검색.
