# Listen to Me

Install with `npm install -g listenee-ltm` or `pnpm add -g listenee-ltm`, then run `ltm init` in a project and `ltm ui` to open the shared editor.

Supported: Linux x64 (static musl), macOS Apple Silicon, Windows x64. Keep optional dependencies enabled. No install scripts or build permissions are needed.

Standalone binaries and installers: https://github.com/pollux-o4/listeneeLTM/releases
